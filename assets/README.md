# Profile artwork

Static SVG artwork for the profile README. Text is outlined using Space Grotesk 600 and Inter 450 from Google Fonts; no font downloads or scripts run when these images load. Font licenses are in `licenses/`.

Toolkit logos are from [Simple Icons](https://github.com/simple-icons/simple-icons), under CC0; brand names and marks belong to their respective owners.

Project illustrations are conceptual diagrams, not screenshots or claims of production readiness. Mobile variants simplify illustrations and increase the relative size of lettering. Each linked card has an equivalent descriptive alt label and a plain repository link in the README.
