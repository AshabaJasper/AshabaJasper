## About

I'm Ashaba Joshua Jasper. I work across data science, applied machine learning, and software engineering to build systems that help people understand their data and get work done.

At **[Persmon Technologies](https://persmontechnologies.com)**, I build digital systems for businesses, with a focus on analytics, automation, and practical software.

- **Data & analytics:** data preparation, exploratory analysis, predictive modelling, and dashboards.
- **AI & machine learning:** model evaluation, applied ML workflows, and AI-assisted automation.
- **Software & delivery:** APIs, business applications, integrations, deployment, and monitoring.

## Selected projects

A selection of my public work across machine learning and application development.

### [SilverVibe Fraternity](https://github.com/AshabaJasper/SilverVibe-Fraternity)
A SACCO management **demo** with an admin dashboard and member portal, covering savings, loans, shares, and reporting.  
**Next.js · TypeScript · Tailwind CSS**

### [Handwriting Recognition](https://github.com/AshabaJasper/Handwriting-Recognition-in-Python)
A machine learning project exploring neural networks for handwritten alphabet recognition.  
**Python · TensorFlow · Keras · OpenCV**

### [Bookstore Inventory API](https://github.com/AshabaJasper/Bookstore-Inventory-API)
A Spring Boot API project for managing books, authors, categories, and orders.  
**Java · Spring Boot · REST APIs**

### [Bayesian Networks for Medical Diagnosis](https://github.com/AshabaJasper/Medical-Diagnosis-with-Bayseian-Networks)
An exploratory notebook project investigating relationships between symptoms and diagnoses using Bayesian networks.  
**Jupyter Notebook · Probabilistic modelling · Healthcare data**
