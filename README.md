## About

I design and build practical systems end to end: data pipelines and models, REST APIs, and full-stack web applications. My work sits at the intersection of data science, applied AI, and software engineering, with a focus on tools that solve real operational problems for businesses, co-operatives, and non-profits.

- **Currently:** running a technology consultancy, [Persmon Technologies](https://persmontechnologies.com), and building [Learnnovate](https://github.com/Learnnovate-Africa), a non-profit that teaches technology skills.
- **Education:** BSc Computer Science (First Class Honours), Uganda Christian University.
- **Exploring:** MLOps, data engineering, and production-grade applied AI.
